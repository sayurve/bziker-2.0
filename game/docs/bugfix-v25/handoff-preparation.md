# Подготовка самостоятельного проекта

Подготовлены `HANDOFF.md`, `DEPLOYMENT.md`, `.env.example` (существующий контракт сохранён), `package.json` и lock-файл, шаблоны systemd, HTTPS-прокси и GitHub Actions. Упаковщик `scripts/package-handoff.py` создаёт отдельный корень проекта и ZIP. Он не публикует файлы и не выполняет развёртывание.

Пакет включает готовые ресурсы, сервер, клиент, тесты, генераторы и текстовые отчёты. Он исключает рабочие БД, резервные БД, `.env`, зависимости, кэш и два посторонних preview. Исторические бинарные proof включаются только явным флагом. В экспорт добавляются 18 оригинальных PNG, проверенных по ранее сохранённым SHA-256, чтобы исторические byte/pixel проверки работали без каталога компьютера автора.

Код игры при экспорте не меняется. Три теста источников и необязательные импортёры получают переносимые пути; все hash/pixel assertions остаются. Отчёты и README лишаются локальных префиксов путей. Состав, SHA-256 каждого файла, размеры и список адаптаций записываются в `handoff-manifest.json`.

Переносимость проверена в отдельном корне проекта:

- `scripts/check-handoff.py`: 119 разрешённых статических путей, отказ выдачи служебных файлов, регистрация тестового аккаунта и профиля, состояние мира и целостность пустой временной БД — прошли.
- `tests/test_handoff_package_v25.py`: 6 проверок прошли; воспроизводимость ZIP, исключение данных, отказ перезаписи, переносимые исходные тесты, согласованный backup SQLite, сверка неизменности финального снимка и запрет создания архива при неуспешной приёмке.
- Контрольная экспортированная копия: 322 серверных теста и 709 JavaScript-тестов прошли. JavaScript-прогон работал на собственных зависимостях после `npm ci`. Временный сервер и тесты не обращались к рабочей БД.
- Сервер контрольной копии инициализирован на одноразовом клоне выбранного backup v25: все 33 таблицы и 173 строки постоянных данных сохранились, байты исходного backup не изменились.

Окончательный пакет собирают после фиксации всех изменений и повторяют проверки внутри него. Он включает все сохранённые игровые screenshot/PDF доказательства по флагу `--include-proof`. Финальные результаты записываются в `HANDOFF-VERIFICATION.json`, состав и размеры — в `handoff-manifest.json`; архив создаётся только после успешной проверки снимка. Внешний полный design pack не копируется: готовые runtime-ресурсы и 18 оригиналов для строгих проверок уже включены; источник нужен отдельно только для повторного импорта.

GitHub CLI `gh` не обнаружен, удалённый Git-репозиторий у основной рабочей папки не указан. Авторизация GitHub, владелец и имя будущего репозитория не подтверждены. Подготовка отдельной локальной папки и первого commit не означает загрузку в GitHub.

Публичный сервер поддерживает `AUTH_MODE=telegram` с токеном и корневым HTTPS-адресом. `AUTH_MODE=account` отсутствует. Режим `demo` сохраняет логин/пароль, но разрешён только на loopback. Docker не добавлен: серверу достаточно Python со стандартной библиотекой, отдельного сохранённого пути SQLite и TLS-прокси.
