# Интерьеры v8: сохранение положения игроков

При смене планировки занятые места следуют за своим постоянным идентификатором. Игрок остаётся в том же помещении, сохраняет сидячую позу, открытый телефон и начало времени сидения. Его новое положение записывается одновременно в присутствие и долговременные координаты.

Если новая мебель перекрыла старую точку стоящего игрока, сервер выбирает ближайшее свободное место в том же помещении. Сначала учитывается запас 14 пикселей около предметов и стен. Для старых узких планировок предусмотрен проход по допустимым границам. Уже допустимые координаты сохраняются без изменений. При восстановлении положения после отключения используется тот же поиск, а не перенос ко входу.

Чужое или удалённое место снимает только устаревшее занятие: открытый телефон сохраняется, если помещение существует. Удалённое помещение возвращает игрока в город и очищает устаревшую позу, место и таймер. Обычное истечение присутствия продолжает освобождать места по действующим правилам.

Начальная миграция и проверка присутствия используют одну процедуру согласования. Вход в публичные комнаты, права на клановые базы, роли кураторов, активные матчи и экономика не изменены. Отдельных запросов к базе для каждого игрока при проверке интерьерной геометрии нет.

Модуль предметов доступен по обоим явным адресам: `/web/interior-props.js` и `/interior-props.js`.

Проверка:

- До исправления: из первых 9 регрессионных проверок 8 воспроизвели отсутствие согласования, местный перенос заменялся переносом ко входу, отсутствовали адреса нового модуля.
- После исправления: 12 проверок интерьерного присутствия проходят. Проверены оба варианта сохранённой позы сидящего игрока с телефоном, видимость исправленных координат другим игрокам, запуск после миграции, восстановление сохранённой точки, границы, удалённая комната и чужое место.
- Сравнение 1 и 100 игроков в комнате подтверждает постоянное количество чтений базы; повторные снимки не переписывают уже исправленные места.
- Совместно с проверками публичных интерьеров v4, городских мест v7 и телефона v5: 34 проверки проходят. Проверка синтаксиса Python проходит.

Команда воспроизведения из каталога приложения:

```sh
PYTHONPATH=.:tests python3 -m unittest tests.test_interior_presence_v8 tests.test_interiors_v4 tests.test_city_fixtures_v7 tests.test_phone_v5
```

Все тесты используют временные базы. Рабочая база аккаунтов не изменялась для тестирования.
