# Бзикер: сборка работающей игры на Phaser

**Объём:** пользователь расширил задачу с подготовки всех материалов до сборки самой игры на Phaser и проверки её анимаций. Серверные правила, аккаунты, сохранения, кланы, магазины, карточные игры и казино сохраняются.

**Архитектура:** Phaser 4.2.1 управляет игровым холстом, тактом, камерой, объектами и порядком слоёв. Город собирается из отдельных GameObject, а не из снимка всей карты. Существующие независимые художники объектов могут готовить собственные CanvasTexture; полный игровой экран в CanvasTexture не переносится. Подготовленные атласы и метаданные имеют отдельный загрузчик. Сервер Python остаётся источником прав, состояния и денег; клиенты сохраняют проверенные коллизии.

## Ограничения

Исходные изображения и видео Bziker не перезаписываются. Объекты используют настоящие стороны мебели. Нет второго применения root_motion к серверным координатам. Новые действия не меняют кошелёк или доступ по событию из файла анимации. Проверка в окне 390 px не обозначается проверкой физического телефона.
