# Бзикер — планировки помещений v8

Цель: каждое помещение узнаётся по предметам и способу использования, с понятным входом, проходами, зоной обслуживания и местами для общения. Основная проверка — вертикальный экран телефона.

## Решение

- Единый источник планировки: `interiors-map.json`. В нём хранятся предметы, их физические основания, зоны пола, препятствия и места для сидения.
- Три магазина имеют разные сценарии: продуктовые полки и холодильники; одежда и примерочные; мебельные композиции с диваном, столом, спальней и рабочим местом.
- Казино имеет компактные зоны автоматов, карточных столов, обслуживания и ожидания. Расстановка не добавляет новые правила игр.
- Вокзал, клановый холл, вход в «Свою игру», гардеробная, галерея, кафе и терраса получают собственные планировки.
- Графика: современные предметы, светлая основа, тёмные контуры, спокойные цветовые акценты, локальные тени и детали материалов. Отдельная сортировка каждого предмета по глубине.
- Мебель клановых баз сохраняет существующую систему редактирования; публичные помещения перестают использовать универсальную декоративную расстановку.
- Сохраняются идентификаторы помещений, дверей, действий и существующих мест для сидения. Положение сидящего игрока согласуется с обновлённой планировкой.

## Проверка

1. Проход от входа к выходу, обслуживанию и местам для сидения с запасом ширины для персонажа.
2. Совпадение видимой мебели с препятствиями; отсутствие перекрытий и некорректной глубины.
3. Магазины, казино и общественные комнаты на телефоне 320/390 px и компьютере.
4. Регрессии входа/выхода, сидения, телефона, аккаунтов и сохранённого прогресса.
5. Полный набор существующих проверок и запуск из итогового архива.
