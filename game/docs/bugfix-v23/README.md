# Проверка пропорций персонажа v23

Три листа воспроизводятся командой `node scripts/render-actor-proof-v23.mjs`.
Node должен иметь доступ к пакету `@napi-rs/canvas`; пакет доступен в bundled runtime Codex.

- `avatar-after-contact.png`: стандартный мужской персонаж, четыре направления, покой и четыре фазы бега.
- `female-after-contact.png`: то же для стандартного женского персонажа.
- `before-after-front.png`: фронтальный покой из legacy atlas до исправления, текущий фронтальный покой и четыре текущие фазы бега для обоих персонажей.

Все кадры «после» вызывает `drawAvatarCanvas` из `web/avatar.js` с загруженными исходными атласами. Кадр «до» вырезается непосредственно из legacy atlas 48×64 без обработки пропорций. Изображения персонажей не перерисованы.

Текущий detailed atlas содержит кадры 96×128 при `factor=2`: их игровой размер остаётся 48×64. На листах используется `scale=2.5`, то есть полный кадр занимает 120×160 пикселей. При стандартном игровом масштабе 1.25 размер полного кадра составляет 60×80 единиц canvas. Это размер кадра, а не высота непрозрачного силуэта.

Все изображения используют одинаковую линию опоры и выключенное сглаживание. Скрипт также выводит границы непрозрачного силуэта и тёплых пикселей головы для фронтального покоя и первой фазы бега, измеренные через текущий renderer при масштабе 2.
