# Состояние автоматической проверки GitHub

Передача исходников и материалов завершена. Все восемь вложений release опубликованы; их размеры и серверные SHA-256 проверены. Эта заметка относится отдельно к автоматическому тестированию на Ubuntu.

Чистая локальная копия прошла **13 инструментальных, 353 Python и 959 Node тестов**, а также **156 статических маршрутов** с временной БД. Подробности — `verification/project-full.json` и журналы `verification/*-latest.log`.

На GitHub Ubuntu Python-проверки проходят, но полный процесс прерывается с **кодом 143** во время Node-проверок. В диагностическом прогоне видны 349 завершённых Node-тестов, затем управляющий процесс завершается без итогового Node-отчёта. Полный набор из 959 Node-тестов на Ubuntu не подтверждён. **Причина прерывания пока не установлена**; код 143 сам по себе не доказывает нехватку памяти или ошибку игры.

Запуски:

- [Первый main](https://github.com/sayurve/bziker-2.0/actions/runs/38790055569).
- [Тег v2.0](https://github.com/sayurve/bziker-2.0/actions/runs/38790626876).
- [Диагностический main](https://github.com/sayurve/bziker-2.0/actions/runs/38792218188): Node v22.23.3, 4 доступных CPU, 16766414848 байт памяти по `os.totalmem()`.

Workflow `.github/workflows/test.yml` сохраняет полный набор тестов и выводит журналы во время прогона. При публикации игровой код и тесты не менялись. Воспроизведение из корня проекта после установки Node 22+:

```sh
cd game
npm ci --ignore-scripts
cd ..
python3 tools/check-project.py --full
python3 game/scripts/check-handoff.py
```

Проверки на локальном компьютере и целостность публикации не объявляются успешным полным прогоном Node на Ubuntu. Инструкция передачи — [GITHUB_HANDOFF.md](GITHUB_HANDOFF.md).
