# Восстановление исходных материалов Бзикер 2.0

Код: [sayurve/bziker-2.0](https://github.com/sayurve/bziker-2.0). Большая библиотека `materials/Bziker/` передаётся отдельно от Git в [release v2.0](https://github.com/sayurve/bziker-2.0/releases/tag/v2.0).

**Release опубликован.** На GitHub доступны все шесть частей и оба файла описания; размеры и серверные SHA-256 всех восьми вложений совпали с локальными. Оба файла описания скачаны обратно и сверены побайтно. Полная повторная распаковка библиотеки после скачивания с GitHub не выполнялась. Для обычного запуска игры библиотека не нужна: необходимые runtime-ресурсы уже находятся в `game/`.

Архив восстанавливает дерево `materials/Bziker/` и большой манифест `verification/materials-manifest.json`, исключённый из обычного Git-клона. Его подготовленный SHA-256: `a2b673025a765ac5d063dc9ad91965f1bfc0345ba993e52173dad11741b8f85d`. Hardlink aliases восстанавливают повторные имена внутри библиотеки; для работы не нужна соседняя оригинальная папка `Bziker`. Объединять нужно все шесть частей с исходными именами, в их порядке. `materials-release.json` описывает набор, `materials-SHA256SUMS.txt` содержит контрольные суммы.

## Загрузка и восстановление

Все команды выполняйте **в корне клона `bziker-2.0`**, где находятся `README.md`, `game/` и `tools/`. Для загрузки командой нужен установленный GitHub CLI `gh`; при необходимости выполните вход в свой GitHub. Вместо CLI можно скачать те же шесть частей и оба файла описания из release браузером, сохранив имена в корне клона.

Скачать части и описание:

```sh
gh release download v2.0 --repo sayurve/bziker-2.0 \
  --pattern 'bziker-2.0-materials.tar.gz.part-*' \
  --pattern 'materials-SHA256SUMS.txt' \
  --pattern 'materials-release.json'
```

Проверьте все части **до распаковки**. На macOS:

```sh
shasum -a256 -c materials-SHA256SUMS.txt
```

На Linux вместо этой команды:

```sh
sha256sum -c materials-SHA256SUMS.txt
```

После успешной проверки всех файлов объедините поток и распакуйте в корень клона:

```sh
cat bziker-2.0-materials.tar.gz.part-* | tar -xz
python3 tools/verify-materials.py --dest .
```

Последняя команда сверяет восстановленную библиотеку с проектным манифестом, а не только целостность скачанного архива. Она использует извлечённый `verification/materials-manifest.json` и эталоны `art/drafts/redrawn-frames-v1/`, уже включённые в клон; эти файлы сохраняйте. При несовпадении SHA не переходите к распаковке/импорту: восстановите полный исходный набор частей и повторите проверку. Эти команды приведены для macOS/Linux; никаких дополнительных преобразований PNG для восстановления не требуется.

Локальная подготовленная копия прошла полный регресс 13 tools +353 Python +959 Node и 156 статических маршрутов; отдельная проверка исходной библиотеки подтвердила 331189 файлов. Внутри подготовленного архива независимо проверены все 54885 уникальных содержимых, ссылки повторов, манифест и gzip CRC. Удалённая публикация подтверждена отдельно: [отчёт](../verification/github-publication-v2/publication-result.json), [контроль серверных SHA-256](../verification/github-publication-v2/remote-assets-check.json).

После восстановления разработчик может пользоваться локальной `materials/Bziker/` и штатными импортёрами. Материалы остаются вне Git согласно `.gitignore`; повторно загружать их как обычные файлы репозитория не нужно.
