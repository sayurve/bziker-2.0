# Стабильная голова и текстура персонажа v32

Запрос Владислава: убрать вибрацию, оставить волосы статичными для направления, сохранить настоящие шаги и устранить кривизну LEFT относительно RIGHT. В начале предполагался прежний male H7 white6 / skin3 / shirtStyle2 lime8. Фактический интерфейс и отдельная QA-копия показали текущий female H7 white6 / skin7 / shirtStyle2 lime8. Исправление охватывает H7 обеих моделей с их собственными C-головами; реальные итоговые UI-сценарии выполняются на текущем female. Другие причёски в этом проходе не выбираются.

## Причины

В L LEFT authored eye/neck X меняется на4 fine px, RIGHT на3; при масштабе1.25/factor2 это2.5 и1.875 world соответственно. После совмещения по глазам рисунок волос почти одинаков; отдельных часов волос нет. Переход C→L также меняет регистрацию головы.

В PhaserWorldRenderer реальная ширина объекта240 при дробном X получает rasterBounds шириной240/241. При шаге0.5 за121 синтетический кадр реальный paint выделяет121 и удаляет120 текстур персонажа. Это доказательство лишних операций; частота кадров настоящего устройства этим не измерена.

## Выбор

1. Фиксировать только существующий рисунок волос недостаточно: лицо и его опора продолжат смещаться.
2. Выбрано: один канонический native head/hair для каждого направления на общей постоянной опоре в обычных L-позах; настоящие четыре позы тела и конечностей сохраняются. Отдельно постоянный размер texture canvas относительно размеров объекта, независимый от дробной позиции.
3. Полная повторная генерация походки не нужна для этой локальной правки и создаст новую задачу согласования идентичности.

Не менять физику, одежду аккаунта, дистанционные часы шагов, действия, экономику и рабочую БД. Не растягивать голову, не зеркалировать тело и не перемещать прямоугольные полосы конечностей. Составление допустимо только из существующих native RGBA и зарегистрированных семантических масок; прозрачный шов не заполнять придуманными пикселями.

## Последовательность проверки

1. Сохранить реальные исходные кадры LEFT и измеренные native anchors.
2. RED→GREEN: статичная голова/волосы по фазам; отдельные настоящие конечности; непрерывный контакт шеи; одна texture allocation при дробном движении, корректное расширение при смене настоящих границ.
3. Просмотреть native контакт и реальные игровые LEFT/RIGHT, старт/стоп, UP/DOWN. Проверить телефон того же персонажа.
4. Повторить затронутые и общий регресс; сохранить команды, версии и пределы визуального просмотра в verification/static-hair-v32/.

Ни один технический PASS не означает отсутствия всех багов игры или художественной приёмки других причёсок. Физический телефон отдельно не проверен.

## Уточнение фактического образа

`verification/static-hair-v32/actual-selected-female-h7.txt` подтверждает интерфейс «Женский / Хвост / Белый», `actual-selected-avatar.json` — точные параметры отдельной локальной QA-копии. Ранние isolated-* кадры являются baseline female skin7, на которую первоначальная male-only правка не распространялась; их нельзя выдавать за итог после female-исправления. Начальный полный регресс954/952/2 сохранён как initial-full-*; строгие проверки глаз и лица должны выбирать настоящую голову C для H7, L — для остальных стилей. Обнаруженное отсутствие authored face-polygon пикселя исправляется в compositor, не допуском теста.
