# Проектные навыки Бзикер 2.0

Профиль: **В — Владислав**. Навыки лежат в `.agents/skills/` этого проекта. Все пути и команды в них отсчитываются от корня проекта, команды игры — из `game/`. Навыки читают текущий контракт и существующие инструменты, поэтому поддерживают разные последующие задачи в пределах проекта.

| Запрос | Навык |
| --- | --- |
| Реализовать или исправить игровую механику, мир, мобильный UI | `$bziker-build-game` |
| Подготовить/изменить позы, одежду, слои и общий цикл анимации | `$bziker-character-pipeline` |
| Проверить сборку, сценарии, ресурсы и фактический результат | `$bziker-game-qa` |

## Активация

Открой проект как рабочую папку Codex. Навыки размещены в проектном каталоге обнаружения `.agents/skills/`; автоматический выбор оставлен включённым по умолчанию, явный запрет автоматической активации не задан. Проверка структуры файлов не доказывает, что конкретный текущий сеанс уже обновил свой каталог навыков. После создания при необходимости открой новый диалог в этом проекте и проверь появление имён в списке навыков.

Можно явно написать: «Используй $bziker-build-game для исправления перехода в интерьер» или «Используй $bziker-character-pipeline для нового комплекта одежды», затем «Используй $bziker-game-qa для проверки этого изменения». Если навык не обнаружен сеансом, прочитай его `SKILL.md` по проектному пути и выполни инструкции. В текущем окружении три навыка также зарегистрированы симлинками из `~/.codex/skills` на проектные папки; редактируемые исходники остаются в `.agents/skills/`. Повторная установка для их использования не нужна.

## Инструменты и свидетельства

Повторяемые операции находятся в корневом `tools/`; перед вызовом сверяй фактический файл и его справку. `tools/import-materials.py` переносит библиотеку в пустое назначение, `tools/verify-materials.py` проверяет байты и происхождение; импортёр принимает `--source`, `--dest` и необязательный `--workers`, самостоятельная проверка копии — `python3 tools/verify-materials.py --dest .` без обязательного внешнего исходника. Повторный импорт поверх готовых материалов не является проверкой. Основные команды из корня:

```sh
python3 tools/run.py --port 8796 --demo
python3 tools/check-project.py --quick
python3 tools/check-project.py --full
python3 tools/check-project.py --materials
```

`--quick` проверяет core/инструменты, `--full` — Python/Node тесты всей игры, `--materials` дополнительно сверяет SHA библиотеки. Локальная игра — `http://127.0.0.1:8796/`; лаборатория персонажей — `http://127.0.0.1:8796/character-lab`. Параметры помощников сверяются через `--help`.

Для исходной игры используются существующие `game/scripts/check-handoff.py`, `game/scripts/test-node.mjs` и `game/tests/`. Не создавай фиктивный PASS, если инструмент не установлен или сценарий не выполнен. Node runner вызывается командой `node scripts/test-node.mjs` из `game/`; Python — `python3 -m unittest discover -s tests -v` из той же папки.

Навыки сохраняют работающие функции Phaser/Python, серверные деньги/права и отдельные PNG. Новые послойные материалы требуют редактируемого мастера и полного покрытия поз/слотов. Исторический `legacy-composite` остаётся совместимостью. Технические проверки, художественная приёмка и физический телефон подтверждаются отдельно; наличие этих навыков не означает завершение игры или одобрение арта.
