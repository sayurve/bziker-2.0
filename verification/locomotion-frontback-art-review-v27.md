# Приёмка native front/back run compatibility v27

Root просмотрел `female-frontback-shared-head-candidate-v27.png` и `male-frontback-shared-head-candidate-v27.png` и одобрил ограниченную run down/up compatibility двух моделей. Wholebody берётся из реальных native run source atlas/rect; одинаковый male run0 alpha-head соответствующего направления применяется ко всем4 фазам обеих моделей. Применяется integer neck translation, не resize лица. Native arms/legs/body ниже y80 сохранены RGBA; detached flesh components кистей сохраняются отдельно, чтобы head-material mask не затронула поднятую руку. Настоящая male нижняя шея сохранена у collar. Body/head candidate просмотрен без видимых разрывов.

Source atlas/rect, authored neck translations и mask evidence сохранены в `art/drafts/locomotion-v27/{male,female}-frontback-shared-head/evidence.json`; donor origin в `shared-head-style-proposal/proposal-evidence.json`. Native female down/up body имеет прежнюю исходную пластику; новые side image_gen тела и эта native front/back совместимость не объявляют полный новый editable wardrobe. Обычная ходьба и отдельные действия сохраняют оригинальную графику; единая идентичность всех legacy actions данным этапом не утверждается.

Регистрация actual native female-up phase0: source shoe заканчивалась наy124, поэтому полный body с его головой зарегистрирован общим integer transfer[0,+1], без отдельных сдвигов конечностей или resize. Нативная форма сохранена, последняя подошва теперьy125 как остальные31 кадр. Последующий общий runtime review выявил разницу female rear body proportions: run102–103px против idle108/male-run115; эта ограниченная совместимость сохраняет identity, но не устраняет исходное более низкое rear torso.
