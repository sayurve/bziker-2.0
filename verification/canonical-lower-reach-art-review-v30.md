# LOWER-REACH B/C: ограниченное художественное одобрение v30

Профиль В. Root выполнил визуальный просмотр двух фактически отрисованных native контактов и передал одобрение исполнителю:

- [Мужские четыре направления](canonical-lower-reach-male-v30-draft.png).
- [Женские четыре направления](canonical-lower-reach-female-v30-draft.png).

Подтверждённый scope: 16 новых полных тел B/C (наклон и приседание), сохранённые женские пропорции, канонические головы без масштабирования, кисти и ботинки внутри общего холста. Не одобрены автоматически все runtime предметы, одежда или редактируемая послойная модель.

LOWER frame0 должен быть точным целым PNG HAND0; LOWER frame3 — точным HAND1. Первые самостоятельные A/D из пилота остаются архивным draft: root отверг их отличающуюся длину стоящего тела. Все 16 B/C пока сохраняются в art/drafts с provenance; production installation допускается только после проверки HAND0/1, metadata и consumer.

Метод: фактические PNG image_gen; один фиксированный uniform scale на соответствующую семью исходников, авторские опора/шея/ладонь, без bbox fit, XY stretch и деформации конечностей. Точная реальная alpha canonical голова своего пола/направления переносится только целочисленно. Исходники и промпты сохранены рядом с каждым sheet. Экспортная сводка: canonical-lower-reach-native-v30.json. Техническая проверка alpha/metadata и runtime tests фиксируется отдельно от этого художественного решения.
