# Браузерная проверка Бзикер 2.0

Проверена работающая копия из `Bzikert 2.0/game` через встроенный браузер Codex. Использовался сервер `tools/run.py --demo --port 8796 --db /tmp/bziker2-browser-qa.sqlite3`, синтетический локальный аккаунт и отдельная временная БД. Соседний исходный проект и его пользователи не использовались.

После QA временный сервер остановлен. Для оставленного открытым просмотра запущен обычный `tools/run.py --demo --port 8796` с новой `data/bziker.db`; лаборатория повторно перезагружена. Синтетический QA-аккаунт в пользовательскую БД не переносился.

## Лаборатория

Фактический движок в DOM: **Phaser 4.2.1**, ready=true. Первоначальный запуск обнаружил `Must set explicit renderType in custom environment`; `Phaser.AUTO` заменён на явный `Phaser.WEBGL`, затем страница перезагружена и сценарии выполнены заново. Историческая ошибка сохранена в console-логе; после исправления новых error/warn в проверенном сеансе не наблюдалось.

- Через кнопки интерфейса выполнены восемь шагов `run/right/0 → … → run/right/7 → run/right/0`. Фаза менялась с шагом 0.125, опора оставалась `48,126`, масштаб — `2×2`.
- Смена полной совместимой палитры на паузе и при воспроизведении дала `swapPreserved=true`: поза/фаза, позиция и масштаб сохранялись в момент замены.
- Неполный комплект с отсутствующим `walk/up/7` отклонён: `rejected=true`, `unchanged=true`; предыдущая текстура сохранена.
- Женская модель переключена и проверена в четырёх направлениях ходьбы; поворот сохранял фазу. Уменьшение движения вернуло фазу и кадр в 0, ручной шаг не накопил скрытую дистанцию.
- При окне 390×844 ширина документа — 390, квадратный stage — 362×362; горизонтального выхода не обнаружено. Временный viewport затем сброшен.

Наблюдения: `browser-character-scenarios.json`, `browser-game-scenarios.json`; изображение — `character-lab-proof.png`. После изменения режима рендера повторно выполнены четыре Node-теста лаборатории — exit 0, лог `character-lab-browser-fix-green.log`.

Лаборатория использует **draft / legacy-composite / один целый слой** из существующей игры. Палитра заменяет всю совместимую позу. Это не демонстрация новой отдельно нарисованной куртки; сидение и предметы в руке в этом стенде явно не подключены. Новые художественные исходники не одобрялись.

## Игра

Проверены экран регистрации, вход синтетического локального аккаунта, город, переход через вход вокзала, движение в его помещении. Настоящий canvas сообщил `renderer=Phaser 4.2.1`, `engineState=scene-ready` и самостоятельные Phaser-объекты.

В окне 390×844 открыт отдельный инвентарь с десятью слотами; затем отдельно открыт Телебзи. Ширина документа — 390; рамка телефона находилась внутри экрана: x=15…375, нижний край 844. Изображение — `phone-mobile-proof.png`. Игровой профиль и регистрация в пользовательской БД этим сценарием не создавались.

## Границы

Проверка выполнена в настольном браузере, включая узкое окно; физический телефон и сетевой multiplayer с несколькими настоящими устройствами не проверены. Не проводилось повторного художественного обхода каждого участка города и каждого старого интерьера. Это не доказательство отсутствия любых багов или завершения новой графики. Большая библиотека отдельно проверена по байтам; логика игры — полным регрессом. Свидетельства не заменяют художественную приёмку новых послойных мастеров.
