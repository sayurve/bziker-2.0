# Независимая проверка новых женских idle-поз — FAIL

Профиль В — Владислав. Решение относится к текущему набору `female-idle-down.png`, `female-idle-right.png`, `female-idle-up.png`, `female-idle-left-v2.png` и его текущему draft-экспорту. Одобрение не выставлено; compiler, export spec, generated data и runtime assets этим этапом не изменялись.

## Просмотренные свидетельства

Просмотрены четыре raw PNG, соответствующие `female-run-*-native.png`, raw мужские idle-мастера и оба контактных листа: `canonical-female-idle-contact.png`, `canonical-idle-contact.png`. Также просмотрены четыре уже экспортированных женских coarse PNG 48×64. Третий пользовательский idle-скриншот не использован.

## Решение по образу

**FAIL: текущий женский набор не следует принимать для замены run-канона.** Волнистые каштановые волосы до плеч, большие контрастные глаза, серая куртка, светлая футболка, чёрные брюки/ботинки и направление каждого вида узнаваемы. Нет подмены пола, другого комплекта одежды, бега вместо покоя или лица на заднем виде. Однако голова и лицо относительно тела заметно меньше исходного женского run; торс/прямые ноги производят более длинную, узкую фигуру. Это особенно видно в down и обоих боковых видах при сравнении на одном контактном листе. Разница не объясняется только расслаблением рук.

Подтверждающий числовой индикатор — ширина head region в фактических frame metadata, `right-left+1`, для idle и первого реального run-кадра. Это вспомогательная геометрическая характеристика, а не автоматическая художественная приёмка:

| Направление | Idle head span | Run frame 0 head span | Idle / run |
| --- | ---: | ---: | ---: |
| down | 26 | 30 | 86,7% |
| left-v2 | 23 | 29 | 79,3% |
| right | 23 | 29 | 79,3% |
| up | 24 | 30 | 80,0% |

Данные взяты из `game/web/canonical-actors-data.js` и `source-actors-data.js`, actions `06_Бег_Спереди`, `07_Бег_Справа`, `08_Бег_Сзади`, `09_Бег_Слева`. Высота metadata head region ограничена алгоритмом экспортёра, поэтому она не использовалась как измерение реального размера лица.

В мужском наборе ширина down/up также немного меньше run (24/26 и 23/25), а боковые виды ближе по этому показателю. Это наблюдение не меняет уже записанный ограниченный статус мужских compatibility idle. Женский набор должен соответствовать собственному женскому run, а не наследовать пропорции мужского idle.

## Опоры и общий масштаб

Проверен текущий `female-export-spec.json`: один `uniformScale=0.10625` для всех видов, fixed canvas48×64 и anchor24,63. Экспортёр использует raw→coarse scale `0.10625/2 = 0.053125`, raw→fine scale `0.10625`; применяет единый X/Y масштаб и перенос авторской опоры. Этот аудит не вычислял новые опоры через fit по силуэту.

| Направление | Авторский sourceAnchor в spec | Raw opaque height, alpha≥128 | Coarse opaque bounds, alpha≥128 | Coarse height |
| --- | --- | ---: | --- | ---: |
| down | [575,1247] | 961 | [11,12,37,63] | 51 |
| left-v2 | [550,1344] | 1004 | [13,10,36,63] | 53 |
| right | [615,1275] | 960 | [10,12,33,63] | 51 |
| up | [535,1300] | 983 | [12,11,36,63] | 52 |

Все видимые подошвы приходят к границе y=63; последний непрозрачный ряд — 62. Регистрация по земле технически согласована. Но left-v2 выше down/right на два coarse пикселя, то есть около 3,9% от их высоты; up на один. По отношению к соответствующим мужским idle женская coarse высота составляет 91,1% down, 96,4% left, 87,9% right, 92,9% up. Поэтому формулировка «везде примерно на 7% ниже мужчины» пока не подтверждается одинаково по всем направлениям.

Это различие рисунков, а не разные Container scales. Его нельзя исправлять независимым масштабом каждого кадра, bbox-нормализацией или растяжением X/Y. Текущие опоры указаны для воспроизводимости, а не как художественно одобренные landmarks.

**portraitChin для нового женского набора не утверждён.** После FAIL рисунков назначать окончательные portrait landmarks преждевременно; в текущем female export spec portraitChin отсутствует. Root отдельно подтвердил, что draft-портреты до art PASS необязательны. Координаты головы из автоматического headRegion не следует выдавать за проверенный подбородок.

## Одна разрешённая целевая итерация female-down-v3

По отдельному поручению выполнен **ровно один built-in image_gen edit** в новый sibling `art/drafts/canonical-idle-v2/female-idle-down-v3.png`. Primary reference — реальный `female-run-down-native.png`; прежний female down использован только для расслабленной позы и композиции. Мужской idle не передавался генератору. Промпт и metadata сохранены рядом.

Оригинальный выход сохранён без crop/resize/repaint: **1150×1367**, true RGBA alpha0…255, alpha≥128 bbox `[319,325,828,1224]`, высота 899. Просмотр сохранённого файла подтвердил фронтальный вид, волосы/одежду, руки вниз и обе стопы на земле. Тело стало компактнее, отношение головы к телу улучшилось преимущественно за счёт более короткого тела. Полная ширина hair/silhouette изменилась умеренно (509 вместо 498 raw px); при прежнем coarse scale это около 27 px, тогда как run head span — 30. Эти разные измерения являются диагностикой, а не новым портретным landmark или доказательством одинакового лица.

**v3 остаётся draft, art PASS не выставлен.** Его общая высота на 62 raw px меньше прежнего down; при неизменном общем масштабе он требует отдельного native/contact сравнения после авторской регистрации. Ни остальные три направления, ни общий экспорт автоматически под него не изменялись. Дополнительные генерации и ручное перерисовывание этим этапом не выполнялись.

## Итог

Техническая регистрация текущих четырёх женских draft-кадров воспроизводима; художественная совместимость с женским run пока FAIL. Один кандидат down-v3 сохранён для следующего целевого сравнения. Ни один новый женский кадр этим аудитом не получил approved; готовность новой послойной модели не заявляется.
