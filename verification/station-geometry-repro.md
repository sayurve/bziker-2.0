# Вокзал: воспроизведение пустого пола и исправление геометрии

Профиль В — Владислав. Статус: код и целевые проверки пройдены; основной агент подтвердил фактический браузер после перезапуска. Художественного одобрения новых PNG этот отчёт не даёт.

## Проверяемая причина

Просмотрены `verification/browser-station-entry-v2.png` (1204×926) и исходный `materials/Bziker/01_Окружение/Здания/ЖД_вокзал/Интерьер/основной.png`. В генераторе `game/scripts/build-modular-interiors.py` номинальная высота пола station=620 умножалась на аспект отдельного пола 761/202. Физическая ширина становилась 1588.30495, глубина 520; размеры мебели и актёра задавались независимо. Получились две лавки шириной 168.170732, разделённые пустым проходом 940.134218.

Камера сама не увеличивала зал: при позиции входа (1248,764), canvas 1204×880, DPR=2, zoom=1.25 функция `worldCamera` давала scale=1.5, x=846.6667, y=342.3333, видимый мир 802.6667×586.6667. Обе лавки находились за горизонтальными краями. В кадр едва попадал верхний левый край второй кассы. На 390×800 лавок тоже не было. Это воспроизводило пустой пол независимо от количества загруженных PNG.

В старой регистрации `game/web/interiors-map-v19.json` исходная ширина пола = (755−14)/0.5 = 1482 native px. Средняя ширина двух лавок = (312+305)/2 = 308.5 px. Отношение 1482/308.5 = 4.80389. До исправления runtime имел 1588.30495/168.170732 = 9.44460: увеличение относительного пространства в 1.966 раза. Отношение промежутка между лавками к лавке было 5.59036 вместо исходного 249/308.5 = 0.80713.

Предыдущая проверка интерьерных материалов и доступности мест не проверяла это отношение и начальную видимость мебели; её результат не был доказательством правильной композиции зала.

## Изменение

Только station уменьшен с 620 до 310. Физический пол теперь 794.152476×210, bounds = left266.923762, right1061.076238, top247, bottom457. Отношение к лавке 4.72230, или 0.983 от исходного (−1.70%). Промежуток между лавками 145.981744. Глубина оставляет место коллизиям и подходам; это адаптированная игровая плоскость, а не утверждение о пиксельном совпадении перспективного оригинала.

PNG, их собственные пропорции, актёр высотой80, ширины мебели и городская дверь не менялись. Общий источник геометрии — генератор; сервер и клиент читают одну `game/web/interiors-map.json`. Десять остальных записей карты сохранены во время замены вокзала; все одиннадцать текущих комнат совпадают с генератором при вычислении в памяти.

Для компактного зала перенесены реальные опоры табло, часов, второй подвесной лампы и настенных светильников. Предварительная проверка ламп отложена только для station до окончательного монтажа; окончательная проверка свободных опор сохранена. Точка кассы перенесена на T+98 между передним краем кассы T+75 и задним краем лавки T+121.8. Иначе прежняя точка T+115 оказалась внутри расширенной коллизии лавки. Выход, все шесть сидений и их подходы остаются действующими.

## Проверка

Новые RED-тесты сначала воспроизвели два сбоя на прежней карте: floor/bench=9.44460 и ноль видимых групп лавок при входе. После изменения оба прошли. На 1204×880 и390×800 обе группы имеют минимум24×24 видимых экранных пикселя. Это расчёт по настоящим функциям камеры и раскладки ресурсов. Основной агент после перезапуска проверил фактические столкновение с лавкой → сидение → телефон → сохранение сидячей позы → вставание и сообщил об адекватном виде390. Отдельно просмотрен реальный `verification/browser-station-after-v2.png`: обе лавки, кассы и границы пола находятся в кадре. Это проверка viewport, а не физического телефона.

- Node: 39/39 PASS — новые `station-room-scale`, исходные shell, human-scale, wall-light, camera, arrival и modular-interiors проверки. В том числе реальное рисование native PNG на canvas, отсутствие наложений всех фоновых деталей, сохранение аспектов и совпадение видимой границы с коллизиями.
- Python: 32/32 PASS по `test_*interior*.py`; ещё 3/3 PASS по `test_station*.py`. Новый серверный BFS с шагом8 проходит от входа к кассе, выходу и каждому подходу сиденья через `world.valid_position`; solids не пересекаются и не выходят за границы. Сидение, телефон, сохранение позиции и перезапуск проверены существующими тестами.
- Пять прежних файлов тестов актуализированы: снято ошибочное требование глубины вокзала≥500; историческая неизменность физики оставлена для остальных десяти комнат; камера маленького зала проверяется на центрирование в доступной области, а не принудительное касание её верхнего края. В двух последних stale-тестах (`interior-layout-v8`, `world-v5`) вокзал проверяется общим `helpers/station-reference-geometry.mjs`: floor/bench в пределах±15% исходного, глубина не меньше исходной при масштабе той же лавки и не больше этой глубины плюс половина высоты актёра для подходов. Остальные десять комнат сохраняют требование≥500. Существующий BFS с радиусом тела14 и шагом4 сохранён. Дополнительный целевой прогон этих двух файлов и `station-room-scale`:19/19 PASS.

Полный Node-прогон после исправления последних stale-тестов: `node scripts/test-node.mjs` из `game`,786/786 PASS,0 FAIL,28.286 секунды. Полный вывод сохранён в `verification/station-node-full.txt`. После этого игровые файлы не менялись.

Целевые команды: из корня проекта `NODE_PATH="$PWD/game/node_modules" node --test` с восемью указанными выше файлами; из `game` — `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*interior*.py' -v` и аналогично `test_station*.py`. Использованы bundled Node/Python. Общий финальный проектный прогон выполняет основной агент после остановки изменений. Оригинальная папка не менялась; коммит не создан.

## Остальные комнаты: измерение без изменения

Полный числовой результат и конкретные пары предметов — в `verification/station-geometry-repro.json`. Измеряется отношение floor/prop относительно одноимённого предмета исходной композиции; это диагностический коэффициент, не автоматическое одобрение или предписание масштабировать комнату.

- casino по двум игровым столам: 1.4645×; messages по столам: 1.1306×; profile и shop-clothes по стойкам одежды: 1.4391×. Удвоения по этим опорам нет.
- arena и results: 3.2326× по центральной статуе, но 1.4654× по двум игровым стойкам. Подтверждено относительное уменьшение статуи; эти разные коэффициенты не доказывают необходимость уменьшить весь зал вдвое. Нужна отдельная визуальная проверка, изменений нет.
- clans, terrace, shop-food, shop-furniture: старые композиции заимствованы у других типов помещений, а нынешние предметы не имеют соответствующей пары в той композиции. Честного исходного floor/prop ratio для них нет. Их самостоятельные исходные референсы этим измерением не подтверждены; изменений нет.
