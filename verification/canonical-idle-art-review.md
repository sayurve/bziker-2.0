# Проверка четырёх новых мужских idle-поз

Эталон пользователя: только `art/references/canonical-run/reference-01.png` и `reference-02.png` (бег). Старый третий idle-скриншот исключён. Просмотрены четыре оригинальных image_gen PNG и контактный лист `canonical-idle-contact.png`, где новые позы стоят рядом с фактическими четырьмя фазами бега.

Приняты для замены мужского покоя **четыре цельные позы**, не послойная модель: сохранены крупная коричневая причёска, большие контрастные глаза, компактный торс, серая куртка, светлая футболка, чёрные брюки и тёмная обувь. Front/left/right/back имеют разные настоящие виды; руки расслаблены, ноги стоят на общей линии. Программного зеркалирования, перестановки конечностей, пересадки головы и растяжения торса при этом экспорте нет.

Исходные генерации не выполняют точную сетку/положение, заданные текстом. Поэтому оригиналы сохранены без изменения; экспорт рисует целую фигуру одним одинаковым масштабом **17/160** во всех четырёх направлениях и переносит заранее указанный авторский root/ground point на общий anchor. Масштаб не вычисляется из bbox каждого кадра; X/Y не расходятся. Runtime-холст48×64, детальный96×128, опора24,63. Координаты регистрации явно находятся в `export-spec.json`; исходные SHA записаны в export report.

Контактный просмотр подтвердил общую стилистику run-канона и отсутствие прежнего узкого/маленького лица покоя. При переходе между ракурсами остаются небольшие естественные различия силуэта, а не изменение масштаба Container. Это ограниченная художественная приёмка новых мужских idle-экспортов для совместимости с текущей игрой. Она **не подтверждает** новую раздельную одежду, полностью одинаковую пиксельную геометрию всех старых действий, готовность женского набора или отсутствие любых визуальных ошибок во всей игре.

Режим — `legacy-composite`, scope — `human-male / idle / four directions`. Правильность декодирования/размеров проверяется отдельно, после включения обязательны native regression и браузерный idle↔run просмотр.
