# Мужские причёски: независимый просмотр настоящих UI-снимков

Входные файлы — `verification/avatar-ui-v27/final/g0-hairStyle-{00..11}-{down,left,up,right}.jpg`, 48 настоящих браузерных изображений. Дополнительно до задания crop просмотрены полные кадры00down,00left,11up и11editor. Все 48 world crops просмотрены на двух целых листах page-1.png/page-2.png. Браузер этим агентом не запускался.

Actual source dimensions:1204×925; второй допустимый режим helper1204×926. После просмотра исходных изображений подтверждён QA crop[535,375,135,180], включающий голову, ноги и край опоры во всех 48случаях. Кропы увеличены1.5× для контакта; это аналитическая производная, не игровые изображения. Исходные JPG не изменены, SHA каждого указан в manifest.json.

Во всех12причёсках видны различные силуэты. В этом срезе не замечены обрезки волос/головы, исчезновение тела или смещение стоп при смене причёски. Длинные/волнистые волосы, один/два пучка и хвост различаются в заднем и боковых видах. Это ограниченный визуальный просмотр фактического интерфейса, не blanket approved всего набора.

Помеха художественной приёмке: белая пунктирная рамка доступного действия проходит поверх волос/лба в ряде down/right кадров. Подтверждён источник: `game/web/phaser-scene-paint.js` рисует action strokeRect сdepth999999 поверх актёра. Белые клетки в этих местах нельзя ошибочно считать альфа-пропусками спрайта. Для чистого просмотра лица нужны кадры вне радиуса действия; вопрос глубины подсветки переданroot. Runtime этим аудитом не исправлялся.

Helper: `node verification/avatar-ui-v27/make-contacts.mjs --gender 0 --category hairStyle --source final --label g0-hair-review`. Для нового запуска использовать новое имя подпапки; поддерживаютсяhairStyle/shirtStyle/pantsStyle/headwear/accessory/outfit,0/1gender. При неизвестном размере источника helper завершится вместо автоматической подгонки crop.
